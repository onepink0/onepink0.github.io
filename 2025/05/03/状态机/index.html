状态机的实现

概述

  • 定义: 状态机（Finite State Machine, FSM）是一种设计模式，通过有限的状态和事件驱动来管理系统的行为。
  • 核心元素:
    • 状态（State）: 系统当前所处的条件（如IDLE、RUNNING）。
    • 事件（Event）: 触发状态转换的信号（如START、STOP）。
    • 转换（Transition）: 状态之间的切换。
    • 动作（Action）: 状态转换或持续执行时的操作。
  • 优点: 逻辑清晰、模块化、易维护，适合嵌入式系统。

    交通灯控制系统

    • 系统有三种状态：RED（红灯亮）、GREEN（绿灯亮）、YELLOW（黄灯亮）。

    • 事件触发状态转换：

      • TIMER：定时器到期，切换到下一状态。
      • RESET：重置到红灯状态。

    • 每个状态有持续动作（如点亮对应颜色的灯）。

    • 目标

      • 使用状态表定义状态转换规则。
      • 分离事件处理和状态执行。
